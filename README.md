# StudyDeck · 考研备考工作台

一个**单文件**的考研备考工作台。倒计时、今日作息、任务看板、刷题统计、专注计时、时政速览、进度矩阵 —— 全套备考环节收在一个页面里，打开就能用，不用注册、不用安装、不用构建。

**在线体验**：https://kaoyan-workbench-01199.app.workbuddy.host/

---

## 为什么做这个

备考期间真正消耗人的，往往不是题目本身，而是**每天的安排无处安放**：作息表在备忘录里、任务在一个 App、刷题记录在另一个表格、倒计时靠脑子记。信息越散，每天开机前的决策成本越高。

StudyDeck 的想法很朴素 —— **把一天里需要确认的东西压到一屏**：今天还剩多少天、这个时段该干什么、还有哪些事没处理、最近刷题正确率怎么样。不需要在多个工具之间跳来跳去。

另一个前提是：**它不该要求你交出账号**。所有数据默认只存在你自己的设备上，想跨设备就填一个同步码，不想就纯本地用。

## 功能

| 模块 | 说明 |
| --- | --- |
| 考研倒计时 | 距离初试的天数，自动切换备考阶段（基础启动 / 基础强化 / 黄金强化 / 冲刺前期 / 冲刺后期） |
| 今日作息 | 按时间段展示当天该做什么；内置**在校 / 在职 / 全职备考**三套模板，也可以完全自定义 |
| 任务看板 | 按科目、优先级、截止日期管理任务；完成的任务归档留存，随时可查 |
| 刷题统计 | 按科目记录每日题量与正确数，自动算正确率趋势 |
| 专注计时 | 正计时 / 倒计时，记录每次专注的科目与时长；支持休息提醒 |
| 时政速览 | 按日期攒时政素材，附摘要、收藏理由与原文链接 |
| 进度矩阵 | 从备考起始日到初试日的方块矩阵，一眼看到进度条走到哪了 |
| 阶段时间轴 | 根据初试日期自动生成阶段节点 |
| 日程标注 | 给任意一天挂上临时待办 |
| 我的科目 | 科目名称、颜色全部自定义；改名会同步历史任务与记录 |
| 数据备份 | 一键导出 / 导入 JSON（含科目、作息模板在内的全部数据） |

另有桌面小组件、半透明壁纸模式等细节。

## 快速开始

1. 下载仓库里的 `index.html`（以及同目录的 `wb-cloud-sdk.js`）
2. 双击打开 —— 完事

推荐 Chrome / Edge / Safari。手机浏览器打开后可以「添加到主屏幕」，当 App 用。

首次打开进「设置」填一下**考试日期**、**起始日期**和**我的科目**，其余都有默认值。

## 数据与云同步

**默认**：数据存在浏览器本地（`localStorage`），不联网、不上传。

**想跨设备同步**（手机 + 平板 + 电脑），页面内置了「同步码」机制：

1. 在「设置 → 设备同步」里点「生成新码」，得到一串 12 位字符
2. 在另一台设备的同一位置输入这串码，点「连接」
3. 之后两台设备自动双向同步

一个同步码 = 一份独立的数据空间，互不干扰。

### 自己配置云端

仓库里的 `index.html` 顶部有一段 `WB_CFG`，需要填成**你自己的**后端配置：

```js
var WB_CFG={
  endpoint:'YOUR_ENDPOINT',
  oauthRelayBaseUrl:'https://www.workbuddy.cn/v2/as/genie-baas/oauth',
  publishableKey:'YOUR_PUBLISHABLE_KEY'
};
```

留空或保持 `YOUR_` 开头时，页面自动降级为**纯本地模式**，功能完全可用，只是不跨设备同步。

云同步依赖 [WorkBuddy Cloud Service](https://www.workbuddy.cn/docs/workbuddy/Overview)（数据库 + 免密钥调用），采用的是「同步码分区 + 受限 RPC」方案：数据表本身对外完全关闭，读写只经过两个受控的数据库函数，函数内部校验同步码格式。详见仓库代码中 `云同步数据层` 一段。

## 技术说明

- **纯静态单文件**：`index.html` 内联全部 HTML / CSS / JS，零构建、零依赖、零框架
- **数据层**：`localStorage` 作本地存储与离线兜底；云端在线时按 key 增量同步（只推改动的字段，避免多设备互相覆盖）
- **冲突策略**：变更后 1.2 秒防抖上传；切回前台 / 每 60 秒拉取一次；本地有未推送改动时不会被远端覆盖
- **样式**：孟菲斯（Memphis）风格，纯手写 CSS，无 UI 库
- **适配**：移动端与桌面端同一套代码，响应式布局
