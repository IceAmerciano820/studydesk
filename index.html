开机自启增强使用率

作为已安装的 PWA 应用，可设置为开机/打开设备即启动：

  1. 电脑 Chrome：地址栏右侧安装图标 → 安装此应用 → 安装后右键固定到任务栏/设为开机启动项
  2. iPad/iPhone：Safari → 分享 → 添加到主屏幕 → 长按图标可设为开机展示
  3. 安卓 Chrome：菜单 → 添加到主屏幕 → 设置 → 应用 → 设为自启动
  4. 桌面快捷方式：安装后从开始菜单拖到"启动"文件夹（Windows）或登录项（Mac）
